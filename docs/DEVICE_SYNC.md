# Sync Brio between devices

Open **Settings → Devices** on your phone, tablet, or TV. On the device whose
library you want to transfer, select **Show pairing code**. On the other device,
enter the six digits and select **Sync with code**. Both devices must be running
Brio on the same Wi-Fi network. The code expires after five minutes and works
once. The devices exchange and merge their watchlists and viewing progress in
both directions; use a new code when you want to sync again.

If network discovery cannot find the device, enter the displayed `IP:port`
address in the optional field on the receiving device. Some guest Wi-Fi and
mobile hotspots block device-to-device traffic; use a network that permits it.

This is a manual local transfer, not an account or an automatic cloud backup.
No Firebase, Supabase, administrator configuration, email address, or Google
account is required. Stream URLs, local files, provider settings, and API keys
are not transferred. Keep those configured on each device separately. Only
movies and TV shows with catalog IDs can be included in shared progress.
